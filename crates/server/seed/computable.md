A number is *computable* if a machine can print its digits one by one, forever.

Most real numbers are not: there are only countably many machines, but
uncountably many reals.

## Why

The machines can be listed, $M_1, M_2, M_3, \dots$, so the computable numbers
are countable. Cantor's diagonal argument shows the reals are not:

$$
|\mathbb{N}| = \aleph_0 < 2^{\aleph_0} = |\mathbb{R}|
$$

| Set | Size |
|---|---|
| Machines | $\aleph_0$ |
| Real numbers | $2^{\aleph_0}$ |
